# QuickLinker - 快速連結與智慧搜尋瀏覽器擴充功能

![QuickLinker Logo](icons/icon128.png) <!-- 假設您會將 logo 放在 icons/icon128.png -->

## 專案簡介

QuickLinker 是一款專為提升瀏覽效率而設計的瀏覽器擴充功能。它允許使用者自訂常用網站的搜尋連結，並透過兩種核心機制提供極致便利：強大的**右鍵選單整合搜尋**，以及創新的**智慧浮動按鈕**，後者能夠自動偵測網頁內容中的特定代碼（例如：影片番號），並即時檢查這些代碼在您預設網站上的可用性。

本專案旨在提供一個高度可配置、直觀且高效的工具，幫助使用者快速導航至所需資訊，尤其適用於需要頻繁搜尋特定格式代碼的場景。

## 核心功能

*   **自訂右鍵選單搜尋：**
    *   允許使用者新增、編輯、刪除和排序多個自訂搜尋網站及其版本。
    *   選取網頁文字後，可透過右鍵選單快速在預設網站上進行搜尋。
    *   支援多層級選單，方便管理大量搜尋來源。
*   **智慧浮動按鈕 (Smart Floating Button)：**
    *   **自動偵測：** 智慧識別網頁內容（剪貼簿、URL、頁面標題）或選取文字中的特定代碼格式（例如 `XXX-YYY` 或 `XXXX-YYY`）。
    *   **即時可用性檢查：** 對偵測到的代碼，自動向您配置的網站發送請求，檢查連結的可用性（例如：是否為 404）。
    *   **視覺化狀態提示：** 浮動按鈕展開後，各網站連結會以不同顏色標示其可用性狀態（綠色：可用，紅色：不可用，橘色：錯誤，黃色：檢查中）。
    *   **可拖曳介面：** 浮動按鈕可在網頁上自由拖曳，不干擾瀏覽。
*   **直觀的設定管理介面：**
    *   透過擴充功能彈出視窗，提供友善的 UI 進行網站與版本的增、刪、改、查。
    *   支援網站與版本的拖曳排序功能。
    *   **掃描模式設定：** 可選擇「最佳結果模式」（找到第一個可用連結即停止）或「完整掃描模式」（檢查所有配置連結）。
    *   **設定匯入/匯出：** 方便使用者備份、遷移或分享其自訂設定。

## 安裝指南

QuickLinker 是一個 Chrome 瀏覽器擴充功能。您可以透過以下步驟將其載入到您的瀏覽器中：

1.  **下載專案：** 從 GitHub 倉庫下載本專案的壓縮包，並解壓縮到您電腦上的任意資料夾。
2.  **開啟 Chrome 擴充功能頁面：**
    *   在 Chrome 瀏覽器中輸入 `chrome://extensions` 並按下 Enter。
    *   或者，點擊瀏覽器右上角的「三點」選單 -> 「更多工具」 -> 「擴充功能」。
3.  **啟用開發者模式：** 在擴充功能頁面的右上角，開啟「開發者模式」開關。
4.  **載入未封裝的擴充功能：** 點擊左上角的「載入未封裝項目」按鈕，然後選擇您剛才解壓縮的 QuickLinker 專案資料夾。
5.  **完成：** QuickLinker 擴充功能現在應該已經成功載入並顯示在您的擴充功能列表中。您可以將其釘選到工具列以便快速存取。

## 使用說明

### 1. 右鍵選單搜尋

1.  在任何網頁上，選取您感興趣的文字。
2.  右鍵點擊選取的文字。
3.  在彈出的上下文選單中，將滑鼠移至「使用「[您選取的文字]」搜尋」。
4.  從展開的子選單中選擇您想使用的網站或版本。
5.  新的分頁將會開啟，並顯示該網站上與您選取文字相關的搜尋結果。

### 2. 智慧浮動按鈕

*   **自動觸發：** 當您瀏覽的網頁內容（例如：剪貼簿、URL、頁面標題）中包含符合您設定的代碼模式時，一個 `+` 浮動按鈕會自動出現在網頁的右下角。
*   **手動觸發：** 您也可以選取網頁上任何符合 `XXX-YYY` 或 `XXXX-YYY` 格式的文字，浮動按鈕也會隨之出現。
*   **使用按鈕：**
    1.  點擊 `+` 浮動按鈕，它會展開並顯示一系列子按鈕，每個子按鈕代表一個您在設定中配置的網站版本。
    2.  子按鈕的顏色會即時反映該連結的可用性：
        *   **綠色邊框：** 連結可用。
        *   **紅色邊框：** 連結不可用（例如 404 錯誤）。
        *   **橘色邊框：** 檢查連結時發生錯誤。
        *   **黃色邊框（動畫）：** 正在檢查連結中。
    3.  點擊綠色邊框的子按鈕，將會在一個新的分頁中開啟該連結。
*   **拖曳按鈕：** 您可以按住 `+` 浮動按鈕並拖曳它到網頁上的任何位置。

### 3. 設定管理介面

點擊瀏覽器工具列上的 QuickLinker 圖示，將會開啟設定彈出視窗。

#### a. 網站管理 (Saved Sites)

*   **網站列表：** 顯示所有已儲存的網站及其版本。
*   **拖曳排序：** 您可以拖曳網站或其版本來調整它們在右鍵選單和浮動按鈕中的顯示順序。
*   **展開/收合：** 點擊網站名稱旁的 `▼` 圖示可以展開或收合該網站的版本列表。
*   **編輯網站/版本：** 點擊鉛筆圖示可以修改網站或版本的名稱和基礎 URL。
*   **刪除網站/版本：** 點擊垃圾桶圖示可以移除網站或版本。
*   **新增版本：** 在每個網站的展開視圖中，您可以為該網站新增更多版本。
*   **匯出設定：** 點擊「匯出」按鈕，將當前所有設定儲存為 `quicklinker_settings.json` 檔案。
*   **匯入設定：** 點擊「匯入」按鈕，選擇一個 `quicklinker_settings.json` 檔案來載入設定。

#### b. 掃描設定 (Scan Settings)

*   **掃描模式：**
    *   **最佳結果模式：** 智慧浮動按鈕在找到第一個可用的連結後即停止掃描，以節省資源。
    *   **完整掃描模式：** 智慧浮動按鈕會檢查所有配置的連結，即使已找到可用連結。
*   選擇您偏好的掃描模式。

#### c. 新增網站 (Add Site)

*   **網站名稱：** 輸入您想新增的網站名稱（例如：JavDB）。
*   **基礎 URL：** 輸入該網站的基礎 URL。**請務必使用 `{}` 作為您希望搜尋代碼（番號）的佔位符。**
    *   **範例：** `https://javdb.com/v/{}`
    *   當您搜尋 `ABC-123` 時，擴充功能會自動替換為 `https://javdb.com/v/ABC-123`。
*   點擊「儲存網站」按鈕以新增。

## 隱私與安全

QuickLinker 擴充功能僅在您的本地瀏覽器環境中運行，並將所有自訂設定儲存在瀏覽器的同步儲存空間 (`chrome.storage.sync`) 中，這意味著您的設定會在您登入的 Chrome 裝置間同步。

*   **所需權限：**
    *   `contextMenus`: 用於創建右鍵選單。
    *   `storage`: 用於儲存您的自訂網站設定和掃描模式。
    *   `activeTab`: 允許擴充功能在當前活動的分頁上執行腳本，用於智慧浮動按鈕。
    *   `scripting`: 用於在網頁中注入內容腳本 (`content.js`)。
*   **網路請求：** 智慧浮動按鈕功能會對您在設定中提供的 URL 執行 `HEAD` 請求，以檢查連結的可用性。**請注意，擴充功能會嘗試連接到您配置的任何 URL。我們強烈建議您只輸入您信任的網站 URL，以避免潛在的安全風險。**

## 常見問題 (FAQ)

*   **Q: 為什麼右鍵選單沒有出現？**
    *   A: 請確保您已選取了網頁上的文字。如果仍然沒有，請檢查擴充功能是否已啟用，或嘗試重新載入擴充功能。
*   **Q: 為什麼智慧浮動按鈕沒有出現？**
    *   A: 請確認網頁內容中是否存在符合您設定的代碼模式，或者您是否選取了符合 `XXX-YYY` 或 `XXXX-YYY` 格式的文字。
*   **Q: 我可以新增多少個網站？**
    *   A: 理論上沒有嚴格限制，但過多的網站可能會影響擴充功能的性能。
*   **Q: 匯入設定後，我的舊設定會被覆蓋嗎？**
    *   A: 是的，匯入的設定會完全取代您當前的設定。建議在匯入前先匯出當前設定進行備份。
