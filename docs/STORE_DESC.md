QuickLinker - 智慧連結聚合與快速搜尋工具

  透過智慧內容偵測和即時多站搜尋整合，大幅提升您的搜尋效率。QuickLinker
  能自動提取網頁中的關鍵資訊，讓您即時在多個平台搜尋相關內容。

  🎯 核心特色

  • 智慧內容偵測：自動提取網頁中的 ID、編號、代碼等關鍵資訊
  • 即時多站搜尋：一鍵在多個網站同時搜尋，即時顯示連結可用性
  • 右鍵選單整合：選取任何文字即可快速搜尋
  • 高度可客製化：自訂搜尋網站、掃描模式等設定
  • 現代化介面：漂亮的漸層設計和流暢動畫
  • 隱私優先：所有數據本地儲存，不收集任何資訊

  ✨ 使用方式

  1. 訪問任何網站，QuickLinker 自動偵測相關內容
  2. 右下角出現浮動按鈕
  3. 點擊展開查看所有可搜尋網站
  4. 顏色標示狀態：
     🟢 綠色邊框：連結可用
     🔴 紅色邊框：連結不存在 (404)
     🟠 橘色邊框：檢查時發生錯誤
     🟡 黃色邊框：檢查中
  5. 點擊任一網站按鈕即可跳轉搜尋

  🎨 進階功能
  • 可拖曳浮動按鈕 - 放置在螢幕任何位置
  • 兩種掃描模式：最佳結果（最快）或完整掃描（完整資訊）
  • 分頁管理 - 選擇搜尋後是否關閉原始分頁
  • 匯入/匯出設定進行備份和分享
  • 自訂搜尋網站，使用 {} 作為關鍵字佔位符

  🔒 隱私與安全

  ✅ 所有設定僅儲存在本地瀏覽器
  ✅ 不收集任何個人資訊
  ✅ 不傳送數據到外部伺服器
  ✅ 開源代碼，可審查

  適合開發者、研究人員、購物比價者，以及任何需要頻繁跨網站搜尋的使用者！
